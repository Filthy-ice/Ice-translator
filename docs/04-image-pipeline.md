# 图片翻译流水线设计

对应需求：FR-2.1~2.9。对应 ADR：ADR-002（OCR 选型）、ADR-003（回写策略）。

整条链路是 `解码 → 检测/识别 → 行合并 → 逐块翻译 → 背景估计 → 擦除或覆盖 → 文字排版 → 绘制 → 导出`。设计原则：**每一环的产物都是可编辑、可视化的中间数据**，因为端到端自动评测做不到，人必须能在中间任何一环接手。

## 1. 阶段定义与产物

| 阶段 | 输入 | 输出 | 失败处理 |
|---|---|---|---|
| S0 载入 | 文件/剪贴板/拖拽 | `RgbaImage` + 尺寸 | 解码失败 → 提示"图片格式不支持或已损坏"；超过 8000px 边长 → 提示并按比例缩到上限处理，导出时明确"已缩放" |
| S1 识别 | `RgbaImage` | 行级观察 `Vec<RowObservation>`（文本、归一化框、置信度） | Vision 报错 → `Recognition`；结果为空 → `NoTextFound`（不是错误，界面提示"未发现文字"） |
| S2 坐标转换 | 归一化左下坐标 | `PixelRect`（左上原点，像素） | 纯函数，单测覆盖翻转与缩放 |
| S3 行合并 | 行观察 | `OcrDocument{ Vec<TextBlock> }` | 合并错误由用户在列表里拆分纠正（FR-2.3） |
| S4 翻译 | `TextBlock.text` 集合 | 填充 `translation` 字段 | 单块失败不影响其它块；失败块标红并可单独重试 |
| S5 背景/前景估计 | 块框 ± 边缘采样 | `BackgroundEstimate{ bg, fg, variance, kind }` | 采样区不足（贴边块）→ 缩小采样带 |
| S6 版式计划 | 块框 + 译文 + 字体度量 | `BlockPlan{ InPlace | Overlay | Skip, font_size, lines }` | 超容量且不允许覆盖 → 标 `degraded` |
| S7 合成 | 源图 + 计划 | `CompositeOutput` | 字体缺失 → 回退并记录警告（R-6） |
| S8 导出 | 结果图 | PNG/JPEG 文件 或 剪贴板图片 | 写文件失败 → 保留结果图在内存，提示重试 |

## 2. S3 行合并算法（决定翻译质量的关键）

OCR 返回的是**行**，翻译需要**语义段**。不合并会得到破碎译文（"免费"/"配送" 各翻各的），过度合并会把表格两列搅浑。

判定两行是否属于同一块，全部满足才合并：

1. **左边界对齐**：`|a.x - b.x| < 0.6 × 平均字高`
2. **垂直间隙合理**：`gap < 1.3 × 行高`（行距通常是 1.2~1.5 倍）
3. **水平重叠充分**：投影重叠长度 > 较窄行的 40%
4. **不是新段落**：若 `b` 是新的起始行（首行缩进、且上一行未填满宽度 85%），停止合并
5. **表格防护**：若同一 y 带上存在 x 方向不连续的多组行（≥ 2 列），判定为表格行，**不跨列合并**

参数集中在 `MergeParams`（默认 `row_gap_factor = 1.3`、`align_tol_factor = 0.6`、`overlap_min = 0.4`、`fill_ratio_para_break = 0.85`），在样图集上调，调完写进验收报告。

**上限**：单块最多 12 行 / 1200 字符，超出即断开，避免一次翻译吞掉整张图。

## 3. S5 背景与前景估计

```
采样带 = 块框向外扩 padding(2px) 的一圈边框像素（不含框内）
bg = 采样带颜色直方图众数（量化到 4bit/通道）
variance = 采样带内与 bg 距离 > 阈值的像素占比
fg = 框内像素中与 bg 距离最大的那一簇的众数
kind = variance < 0.15 → Uniform（可回填）
       0.15~0.35       → Gradient（回填 + 边缘过渡）
       > 0.35          → Complex（强制覆盖层）
```

- 覆盖层底色：取 `bg` 的加深/变亮版本（按 `fg` 与 `bg` 的相对亮度决定），保证对比度 ≥ 4.5:1；不硬编码"半透明黑底白字"。
- 透明/Alpha 图片：以 alpha 加权参与统计，导出保留 alpha。

## 4. S6/S7 版式与绘制

1. **字号**：起始 `block.estimated_font_size()`（0.75 × 框高）。
2. **测量**：用实际字体度量算每行宽度，而不是按字符数估算（`Language::width_factor` 只在预算不足时做初筛）。
3. **换行**：CJK 按字符断行（`Language::breaks_by_char`），拉丁按词断行，标点不落行首。
4. **自适应**：若 N 行超出框容量，按 0.95 步进缩字号，直到 `min_font_scale`（0.55）；仍超 → `Overlay`。
5. **对齐**：沿用原块对齐（依据首行左边界与块框中心的相对位置推断左/中/右）。
6. **擦除**：`Uniform` 用实心矩形；`Gradient` 用四角双线性插值填充，再加 1px 模糊边缘；`Complex` 不擦。
7. **倾斜块**：若 `polygon` 存在且主轴角 > 5°，用逆仿射把该区域拉正 → 绘制 → 正仿射贴回（P7 若来不及，明确记录为已知限制并统一走覆盖层）。
8. **绘制顺序**：先全部擦除，再全部绘制文字，避免后画的字被前块的擦除盖掉。

## 5. 质量评估办法（P6/P7 验收依据）

自动指标只有一条可信：**字符正确率**（OCR 层，用人工标注样图集算编辑距离）。其余都要人看。

样图集（`assets/samples/`，至少 10 张，覆盖：纯文本报错弹窗、PPT 页、产品说明书、表格截图、中英混排、艺术字标题、深色模式截图、低对比度、照片背景文字、多栏排版）。

| 指标 | 计算 | 目标 |
|---|---|---|
| OCR 字符正确率 | 1 − 归一化编辑距离 / 标注长度，逐块算后取均值 | ≥ 0.92（排除艺术字与照片背景两类） |
| 段落合并正确率 | 人工判定"块边界合理"的比例 | ≥ 0.85 |
| 回填可读性 | 人工 1~5 分：译文完整、无裁切、无重叠 | 均值 ≥ 4.0 |
| 回填位置准确性 | 人工 1~5 分：在原文区域内、对齐合理 | 均值 ≥ 3.5 |
| 观感自然度 | 人工 1~5 分：底色、字号协调 | 均值 ≥ 3.0（允许不完美） |
| 覆盖层可用率 | `Complex` 块中结果可读的比例 | ≥ 0.9 |

评分表模板在 `06-test-cases.md`，打分记录与失败样例进 `docs/evidence/p7-scoring.md`，不合格样例转入已知限制清单，不无限追查。

## 6. 已知限制（预先声明，避免验收时争论）

| 编号 | 限制 | 影响 | 兜底 |
|---|---|---|---|
| L-1 | 照片/纹理/渐变背景无法无痕擦除 | 生成图有补丁感 | 覆盖层模式（FR-2.5） |
| L-2 | 艺术字、手写体、描边字效果不复现 | 观感下降 | 保留文本正确性，效果放弃 |
| L-3 | 表格与多栏排版可能串行错位 | 需人工干预 | S3 表格防护 + 列表可编辑 |
| L-4 | 译文比原文长 2 倍以上的窄块只能缩字号或覆盖 | 小字号可读性差 | `degraded` 标记提示用户 |
| L-5 | 倾斜/竖排文字 v1 可能统一走覆盖层 | 版式不如原文 | 记入延期项 |
| L-6 | 非 macOS 平台无 OCR | 图片功能不可用 | 明确提示，文本功能不受影响 |
